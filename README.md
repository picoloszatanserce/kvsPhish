# kvsPhish
kvsPhish to otwartoźródłowe narzędzie do symulacji ataków phishingowych, stworzone dla etycznych hackerów, pentesterów oraz administratorów systemów w celu audytu świadomości bezpieczeństwa użytkowników.


# Wersja programu
program obecnie jest jeszcze w czasie testów. Instrukcje co do uzywania programu znajdziesz po zakończeniu pracy nad wersją **1.0**.
